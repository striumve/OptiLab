# OptiLab 三维光电实验室

Three.js + Vite 本地交互教学应用。场景占满整个浏览器工作区，操作面板悬浮于场景之上。

## 启动与检查

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
npm test
npm run build
```

浏览终端打印的本地地址；若 5173 已占用，Vite 会自动递增端口。生产文件输出至 dist。

## 使用方式

- 每次打开默认是**自由搭建、空实验台**，不自动恢复旧实验。
- 点击「实验与仪器」显示或收起左侧面板，仪器库与实验列表可分别折叠。点击器件即可添加。
- 仪器可沿台面 X / Z 两个方向自由拖动。属性面板可精确调节厘米位置和各仪器参数。选中仪器时面板自动打开。
- 拖动空白处环绕、滚轮缩放。可切换俯视与透视。
- 「专注场景」收起全部操作浮层，Escape 或「退出专注」返回；「全屏」请求浏览器全屏，部分嵌入式浏览器可能不支持，可改用专注场景。
- 「实验观测」展开实时接收画面、理论曲线与数值。默认收起。
- 选择预设会重新搭台；「自由搭建」和自由模式下的「重新搭台」会清空当前场景。切换前可保存。
- 保存使用浏览器 localStorage；「恢复实验」手动载入已保存实验。CSV 导出模型参数、强度采样、电压与时间采样。不同本地端口拥有独立浏览器存储。

## 7 项实验预设

| 实验 | 可调参数与观测 |
| --- | --- |
| 薄透镜成像 | 焦距、物距、屏距，近轴光线和理论像距 |
| 杨氏双缝干涉 | 波长、缝距、屏距，条纹间距 |
| 偏振与马吕斯定律 | 各偏振片角度、功率，透射强度与角度扫描 |
| 单缝夫琅禾费衍射 | 缝宽、波长、屏距，中央亮纹与旁瓣 |
| 光栅衍射与测波长 | 线密度、有效缝数、波长，一级衍射角与强度 |
| 光电探测与响应度 | 功率、偏振角、响应度、负载，光电流与电压 |
| 光电接收机频率响应 | 调制频率、深度、电阻、电容，示波波形、截止频率、相位和幅频响应 |

共有 10 类仪器，包括光学器件、光电探测器、信号发生器和数字示波器。自由模式会根据光路自动识别观测模型。

## 模型和边界

这是理想光学与一阶电路的教学仿真，非真实硬件控制或工程级光学设计工具。

- 1 个三维台面单位 = 10 cm。光源沿 +X 发射；最左侧激光器为活动光源，横向偏差小于 1.5 cm 的下游器件参与光路，首个观察屏或探测器终止传播。X / Z 可自由摆放，但不包含任意方向光轴、反射光路、碰撞或手动电路接线。
- 预设之外的混合光路按主实验模型显示：探测器优先，然后光栅、单缝、双缝、偏振、透镜。不提供多个衍射器件级联的完整波场传播。
- 薄透镜使用近轴传递；屏上高斯光斑为定性聚焦示意。
- 双缝为无包络远场模型。单缝为 sinc² 远场模型。光栅为有限 N 缝干涉乘单缝包络，固定占空比 25%；观测窗口为 ±20 cm，其余光学模型为 ±8 mm。
- 偏振使用水平线偏振入射，逐片应用马吕斯定律。角度扫描只改变最后一片，前置器件状态保持不变。
- 光源相对功率 1.0 = 1 mW；光电流 I=RP，电阻输出 V=IR。RC 带宽 fc=1/(2πRC)，正弦调制输出包含幅度衰减与相位滞后。
- 发生器自动驱动激光器，探测器自动连接示波器；线缆为示意。示波器显示两个周期的交流分量，无发生器时显示直流读数；不模拟噪声、暗电流、饱和或器件频谱响应。波形随参数更新，而不是时间推进的瞬态求解。
- 暂停光源将光学信号和探测输出归零；理论曲线在适用时保留理论形状。

公式与场景逻辑在 src/physics.js、src/simulation.js，实验配置在 src/experiments.js。浏览器需支持 WebGL。
