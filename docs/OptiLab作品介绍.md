# OptiLab 光电实验智能学习平台

## 作品名称与关键词

作品名称：OptiLab 光电实验智能学习平台
关键词：光电实验、AI助教、三维仿真、数据分析、虚实融合

## 应用场景

本作品面向光电信息、应用物理及相关专业本科生，服务于课前预习、课堂辅助、课后复盘和自主探究。学生可在个人电脑上完成“预习答疑—三维搭建—操作记录—数据分析—结果解读—报告检查”的连续学习流程，也可导入真实实验数据，将虚拟练习与实体实验衔接。教师可将其作为原理演示和实验方法训练的辅助工具。

## 解决的痛点

光电实验涉及抽象的光学原理、精细的器件调节与多步骤数据处理。学生容易出现“看懂公式但不会搭建”“完成操作却难以解释现象”的问题；实体仪器受开放时间和数量限制，课外练习机会不足；数据整理、单位换算、拟合绘图与报告撰写分散在多个工具中，难以追溯结论。通用AI问答又往往缺少当前光路、器件参数与计算结果，容易给出脱离实验条件的解释。OptiLab 将上述环节连接起来，让学习指导围绕具体实验展开。

## AI工具与技术方案

采用大语言模型助教与确定性物理计算协同的方案。AI服务支持OpenAI兼容的Chat Completions和Responses两种协议，可配置第三方服务或本地兼容模型；模型用于生成预习、自测题、学习答疑、结果解读及报告检查。提问时附带实验指导、选中仪器、场景参数和已有分析摘要，使回答具备实验上下文。
前端采用Three.js构建可交互三维实验台，基于薄透镜、马吕斯定律、标量远场衍射、线性光电响应与一阶RC模型呈现实验现象。浏览器本地完成数据解析、最小二乘拟合、残差分析及图表生成，输出适用的R²、RMSE和参数标准误；AI据此解释结果。Node.js本机服务管理模型调用及密钥，Markdown与KaTeX呈现文字、表格和公式。实验记录与场景可保存、备份和导出；未配置AI时仍可使用内置指导、仿真及本地计算。

## 创新点

一是将AI指导嵌入实验全过程：学生可直接针对当前光路、器件和结果提问，减少在实验界面与通用问答工具间反复描述背景。二是形成“物理模型计算—AI辅助解释—学生验证”的协作方式，数值结果由本地算法产生，误差原因作为待验证假设，提升结论的可核查性。三是贯通虚实数据：支持仿真读数采集和实测数据导入，明确区分示例、仿真与实测来源，条纹类实验保留学生判读环节。四是将场景、过程记录、数据、分析与报告草稿关联保存，便于复盘实验条件与推理过程。

## 应用成效与量化指标

目前已形成可本地使用的单用户完整流程应用。功能覆盖薄透镜、双缝、偏振、单缝、光栅、光电响应度、接收机带宽7类专题实验，并提供自由搭建模式；支持10类仪器、9种数据处理模式（含原始曲线展示），其中4类实验可采集当前仿真读数。单次支持最多5000行、2 MB的CSV/TSV数据，浏览器最多保存30份实验记录。
2026年11月16日，本地自动化测试38项全部通过，覆盖物理公式、数据解析与拟合、备份校验、公式排版及AI接口等；AI接口测试采用模拟响应。这些指标证明了当前功能覆盖与基础工程验证情况。教学成效将通过试点进一步评估，现阶段尚无可报告的班级使用规模、成绩提升或时间节省实测数据。

## 推广计划

第一阶段，拟在1门相关课程中邀请20—30名学生开展4周试用，选取2—3项典型实验，记录预习耗时、报告单位与计算错误数及满意度，并通过前后测评估概念理解变化。第二阶段，根据试点反馈完善实验模板、指导内容与操作体验，形成演示视频、学生使用指南和教师教学案例，通过课程群与实验中心推广。第三阶段，在验证教学价值后扩展专题实验，补齐账户权限、课程管理、服务端存储及模型调用配额，再推进班级部署。试点以预习时间降低20%、报告单位及计算错误数减少30%为评估目标，目标值不作为已实现成效。
