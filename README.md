# OptiLab · 光电实验学习应用

面向光电专业本科生的本地应用：实验预习与答疑 → 三维搭建 → 操作记录 → 数据分析 → 结果解读与报告检查。

## 一键启动（Windows）

安装 Node.js 22.12+ 后，双击项目根目录的 **启动OptiLab.cmd** 即可，无需手动输入终端命令，也不需要管理员权限。

启动器会自动检查依赖（首次缺少依赖时自动安装，需要联网）、构建最新页面、启动本地服务，然后打开默认浏览器。启动窗口需保留，关闭窗口或按 Ctrl+C 可停止服务；启动失败时窗口会保留错误信息。

优先使用 .env 的 PORT（默认 5180）。如果端口被占用（EADDRINUSE）或系统禁止绑定（EACCES），自动尝试 5180–5199，再由系统分配空闲端口；启动窗口和浏览器使用实际成功的地址，不再因 1037 无法绑定而退出。不会修改系统端口保留、防火墙或管理员设置，也不会覆盖 .env。

不同端口的浏览器实验记录相互独立；换端口后看不到旧记录时，可在旧地址导出备份再导入。AI 服务配置保存在服务端，不受页面端口变化影响。

## 开发与检查

需要 Node.js 22.12+。也保留以下开发命令：

```sh
npm install
npm run dev
npm test
npm run build
npm start
npm run smoke
```

开发服务与生产服务均支持自动端口回退。npm run dev:scene 为独立的 Vite 场景入口，不包含完整 AI 后端。

## 第一次使用

1. 在学习工作台选择实验。系统新建独立实验记录、摆好三维预设并准备预习。AI 已配置时自动请求预习；否则清楚显示内置指导。
2. 阅读原理与自测题，在答疑区向 AI 提问，或选择「查内置资料」。勾选预习确认。
3. 在操作页查看步骤、器件使用方法和注意事项，记录实际参数、观察及异常。进入三维场景调节仪器，点击「学习工作台」返回。
4. 上传 CSV/TSV，或粘贴带表头的数据。确认数据来源、列映射、单位与模型，点击「计算并绘图」。每个实验有模板和显式标记的示例。
5. 查看计算结果、拟合曲线和残差。可请求 AI 解读结果与提出待验证的误差假设。
6. 在报告页生成含实际计算摘要的提纲，补写真实过程和结论。运行本地结构检查或 AI 检查，导出 Markdown、图表、拟合数据和计算摘要。

## 应用设置与第三方 AI

在学习工作台或实验台点击「应用设置 → AI 服务」：

1. 默认使用 **DeepSeek**，已填好服务地址 `https://api.deepseek.com`、模型 `deepseek-flash` 和 **Responses** 协议。只需填写 DeepSeek API Key。
2. 使用第三方服务时，可修改服务地址和模型，并选择服务商支持的 **Chat Completions** 或 **Responses**。
3. 点击「保存并启用」，即时生效，无需重启。可点击「测试连接」发送简短测试消息。DeepSeek 正文默认边生成边显示。

地址示例：

- 基础地址 `https://your-provider.example/v1` → Chat Completions 请求 `https://your-provider.example/v1/chat/completions`。
- 本地兼容服务可填 `http://localhost:11434/v1`（模型和端口按本机服务实际配置）。
- 也接受完整 `/chat/completions` 或 `/responses` 端点，会规整为基础地址；界面展示最终请求地址。

密钥在首次填写后只发送给本机后端，保存于项目的 .local/ai-settings.json，浏览器不回显、不存储密钥，实验备份也不包含密钥。此文件为本机明文配置，已被 Git 忽略且不提供网页访问。更换服务地址需要重新填写密钥，避免把原服务的密钥发送给新服务。远程服务使用 HTTPS，本机 localhost / 127.0.0.1 可使用 HTTP 并支持免密本地模型。

「恢复环境配置」清除应用内保存的 AI 配置并回到 .env。环境变量仍可用于启动配置：

OPENAI_API_KEY、OPENAI_MODEL 保留兼容；AI_BASE_URL、AI_PROTOCOL、AI_MODEL、AI_API_KEY、AI_PROVIDER 可指定第三方。应用设置优先于环境变量。不要使用 VITE_* 变量存放密钥。

实验台右上方工具栏提供「AI 助教」，无需离开场景即可提问：

- 自动附带当前实验、选中仪器、器件参数和仿真读数。
- 若有匹配的实验记录，会同时附带已计算的数据摘要并共享对话；自由实验对话单独保存于浏览器。
- 内置「当前光路」「仪器用法」快捷问题；未配置 AI 时可查询内置指导，明确标注来源。
- 每次进入实验台默认展开「实验模块与仪器」面板；仍可手动收起，专注模式可隐藏全部面板。

AI 请求将实验资料和相关上下文发送至当前配置的服务商。原始 CSV 留在浏览器，分析摘要最多附前 100 组观测（其余行仍全部参与本地拟合）。Responses 请求设置 store:false；第三方数据保留策略以其规则为准。测试使用模拟响应，不调用真实付费服务。

实现参考：[Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Responses 官方文档](https://developers.openai.com/api/reference/resources/responses/methods/create)。

## AI 回复排版

预习、学习问答、结果解读、报告检查、实验台助教及连接测试回复统一支持 Markdown：标题、粗体、列表、引用、表格、链接和代码块。公式使用 KaTeX 本地排版，支持行内 `$...$` / `\(...\)`、块级 `$$...$$` / `\[...\]`，以及 math / latex / tex 围栏。公式字体随应用打包，无需外部 CDN。

不支持或不完整的公式保留原文；代码中的公式不会误渲染。原始回复仍以文本保存，旧记录刷新后自动使用新排版。渲染关闭原始 HTML，不执行模型返回的脚本或自动加载外部图片。开发时可访问 `/tests/rich-text.html` 检查宽窄面板的排版。

## 数据分析方法

导入 UTF-8 CSV/TSV（最多 5000 行、2 MB），支持引号字段、科学计数法、BOM、`#` 注释。必须有唯一的非空表头。空白或非数值会标出行号，不静默删点。数值须符合界面显示的单位；列名不触发隐式单位换算。

| 模型 | 输入 | 处理与输出 |
| --- | --- | --- |
| 通用线性 | x、y | 最小二乘斜率、截距、R²、RMSE、参数标准误 |
| 薄透镜 | u/cm、v/cm | 1/v 对 1/u 拟合，截距求 f；逐组焦距均值 |
| 双缝 | 亮纹级次、位置/mm | 位置斜率，结合 d/mm 与 L/m 求波长 |
| 偏振 | 角度/°、相对强度 | I 对 cos²(θ−θ₀) 拟合，估计幅度与背景 |
| 单缝 | 非零暗纹级次、位置/mm | 暗纹斜率，结合 a/mm 与 L/m 求波长 |
| 光栅 | 级次、衍射角/° | sinθ 对级次拟合，结合线密度求波长 |
| 光电探测 | 功率/mW、电流/μA | 线性拟合，换算响应度 A/W 与零点电流 |
| 接收机带宽 | 频率/kHz、交流幅值/V | 一阶 RC 非线性最小二乘估计 A₀、fc |
| 原始曲线 | 任意两列 | 散点显示，不拟合 |

线性标准误基于独立同方差残差假设，不包含仪器校准误差。RC 非线性拟合暂不提供参数置信区间；扫频未覆盖截止点时提示不可辨识风险。R² 为拟合诊断，不能等同于实验正确；常量因变量时 R² 不定义。图中蓝点为数据、橙线为拟合；大数据绘图最多抽样 1500 点，全部点参与计算与 CSV 导出。

薄透镜、偏振、响应度和接收机实验可采集当前仿真读数；改变参数后重复采集。条纹类实验需判读级次和位置/角度，不从理论公式生成伪测量数据。

## 三维实验室

- 全工作区场景，操作浮层可收起；「专注场景」收起全部浮层，Escape 返回。浏览器不支持系统全屏时仍可使用专注模式。
- 三维场景本身默认空台自由模式；选择学习实验或三维实验预设会重新搭台。
- 点击仪器库添加、单击器件选中、拖动沿 X/Z 移动；拖动空白环绕、滚轮缩放。
- 10 类器件：激光器、透镜、双缝、偏振片、观察屏、单缝、光栅、探测器、发生器、示波器。
- 最左侧激光器为活动光源，沿 +X 传播；横向偏差小于 1.5 cm 的下游器件参与，首个屏/探测器终止光路。
- 1 个场景长度单位 = 10 cm。薄透镜是近轴模型、光斑为定性示意；单缝/双缝/光栅为标量远场模型；光栅占空比 25%。偏振逐片应用马吕斯定律。
- 相对光源功率 1.0 对应 1 mW。探测器为线性响应与一阶 RC 负载。发生器和示波器自动连接，线缆为示意，暂不支持真实硬件和手动电路接线。
- 不包含非近轴反射光路、碰撞、噪声、暗电流、饱和、损伤和多衍射元件级联波场。混合光路按主模型呈现。

## 保存和备份

- 每份实验独立保存预习、对话、清单、笔记、数据、分析、草稿与三维场景。在实验记录间切换会恢复各自场景。
- 学习记录使用 `optilab-notebooks-v2` 浏览器存储，最多 30 份；无账户、无云同步。不同浏览器、端口和域名的存储独立。
- 关闭/重启浏览器后记录仍在；清除站点数据会丢失，请定期「导出实验备份」。JSON 导入以新记录合并，不覆盖现有记录，且重新校验计算结果。
- 三维场景的「保存实验 / 恢复实验」仍独立保留。三维场景不会在首次启动自动载入旧台面。
- 修改数据或模型会使旧分析解读及报告检查失效。报告提纲不会随数据自动重写，应在最终核对时重新检查。

## 工程结构

- `server.js`：本机 HTTP、开发与生产静态服务。
- `server/assistant.js`：AI 请求、两种协议、上下文、同源校验及错误处理。
- `server/ai-settings.js` / `src/ai-settings.js`：应用内 AI 设置、持久化与连接测试。
- `src/learning.js` / `src/learning.css`：学习工作台与实验记录交互。
- `src/curriculum.js`：内置实验指导和仪器手册。
- `src/analysis.js`：解析、拟合、统计与报告规则检查。
- `src/notebooks.js`：实验备份与场景快照校验。
- `src/main.js` / `src/simulation.js` / `src/physics.js`：三维场景与物理仿真。
- `*.test.js`：公式、分析、场景、备份与 AI 接口测试。

本版本是**可本地使用的单用户完整流程应用**。若用于公网/班级教学，仍需另外增加账户、权限、课程管理、服务端数据存储、配额和部署配置。
