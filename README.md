# OptiLab · 光电实验学习应用

面向光电专业本科生的本地应用：实验预习与答疑 → 三维搭建 → 操作记录 → 数据分析 → 结果解读与报告检查。

## 快速启动

需要 Node.js **22.12+**（推荐使用当前已安装的 Node.js 24）。

```sh
npm install
npm run dev
```

完整应用默认打开 **http://127.0.0.1:5180/**。应用仅监听本机，不需要账户。若端口占用，在 `.env` 中修改 `PORT`。

```sh
npm test          # 物理、数据分析、备份验证与 AI 接口单元测试
npm run build    # 生成 dist
npm start        # 用 Node 服务提供生产资源和 API
npm run smoke    # 构建后验证生产 HTTP 服务（临时端口，不调用真实 AI）
```

`npm run dev:scene` 保留旧的 Vite 场景开发入口；完整 AI 接口需使用 `npm run dev` 或 `npm start`。

## 第一次使用

1. 在学习工作台选择实验。系统新建独立实验记录、摆好三维预设并准备预习。AI 已配置时自动请求预习；否则清楚显示内置指导。
2. 阅读原理与自测题，在答疑区向 AI 提问，或选择「查内置资料」。勾选预习确认。
3. 在操作页查看步骤、器件使用方法和注意事项，记录实际参数、观察及异常。进入三维场景调节仪器，点击「学习工作台」返回。
4. 上传 CSV/TSV，或粘贴带表头的数据。确认数据来源、列映射、单位与模型，点击「计算并绘图」。每个实验有模板和显式标记的示例。
5. 查看计算结果、拟合曲线和残差。可请求 AI 解读结果与提出待验证的误差假设。
6. 在报告页生成含实际计算摘要的提纲，补写真实过程和结论。运行本地结构检查或 AI 检查，导出 Markdown、图表、拟合数据和计算摘要。

## 配置 AI

将 `.env.example` 复制为 `.env`，填写：

```dotenv
OPENAI_API_KEY=你的平台API密钥
OPENAI_MODEL=你的API账户可用的Responses模型ID
PORT=5180
```

重新启动后，在「AI 设置」刷新状态。不要将密钥放入 `VITE_*` 环境变量或浏览器。

- 通过 Node 后端调用 OpenAI Responses API，密钥只从服务端环境读取。配置文件被 Git 忽略。
- 选择新实验时自动生成预习；答疑、结果解读和报告检查由用户按钮触发。
- AI 请求包含该实验的内置资料、当前场景（若匹配）、分析摘要、数据来源和相关对话/正文。不要上传不必要的个人信息。
- 原始 CSV 留在浏览器。AI 分析摘要包含最多前 100 组观测和计算结果，超过时标记截断。数值拟合对全部有效行进行。
- 无密钥时，内置指导、资料检索、本地绘图计算和规则检查可用，**不会伪装成 AI 回答**。
- 接口设置 `store:false`，不创建服务端会话日志。模型服务仍受提供商的数据政策约束。
- 真实模型调用需要用户自己的 API 权限、可用模型、网络及额度；仓库测试使用模拟响应，不消耗模型额度。

实现参考：[Responses API 官方文档](https://developers.openai.com/api/reference/resources/responses/methods/create)、[迁移与会话状态说明](https://developers.openai.com/api/docs/guides/migrate-to-responses)。

## 数据分析方法

导入 UTF-8 CSV/TSV（最多 5000 行、2 MB），支持引号字段、科学计数法、BOM、`#` 注释。必须有唯一的非空表头。空白或非数值会标出行号，不静默删点。数值须符合界面显示的单位；列名不触发隐式单位换算。

| 模型 | 输入 | 处理与输出 |
| --- | --- | --- |
| 通用线性 | x、y | 最小二乘斜率、截距、R²、RMSE、参数标准误 |
| 薄透镜 | u/cm、v/cm | 1/v 对 1/u 拟合，截距求 f；逐组焦距均值 |
| 双缝 | 亮纹级次、位置/mm | 位置斜率，结合 d/mm 与 L/m 求波长 |
| 偏振 | 角度/°、相对强度 | I 对 cos²(θ−θ₀) 拟合，估计幅度与背景 |
| 单缝 | 非零暗纹级次、位置/mm | 暗纹斜率，结合 a/mm 与 L/m 求波长 |
| 光栅 | 级次、衍射角/° | sinθ 对级次拟合，结合线密度求波长 |
| 光电探测 | 功率/mW、电流/μA | 线性拟合，换算响应度 A/W 与零点电流 |
| 接收机带宽 | 频率/kHz、交流幅值/V | 一阶 RC 非线性最小二乘估计 A₀、fc |
| 原始曲线 | 任意两列 | 散点显示，不拟合 |

线性标准误基于独立同方差残差假设，不包含仪器校准误差。RC 非线性拟合暂不提供参数置信区间；扫频未覆盖截止点时提示不可辨识风险。R² 为拟合诊断，不能等同于实验正确；常量因变量时 R² 不定义。图中蓝点为数据、橙线为拟合；大数据绘图最多抽样 1500 点，全部点参与计算与 CSV 导出。

薄透镜、偏振、响应度和接收机实验可采集当前仿真读数；改变参数后重复采集。条纹类实验需判读级次和位置/角度，不从理论公式生成伪测量数据。

## 三维实验室

- 全工作区场景，操作浮层可收起；「专注场景」收起全部浮层，Escape 返回。浏览器不支持系统全屏时仍可使用专注模式。
- 三维场景本身默认空台自由模式；选择学习实验或三维实验预设会重新搭台。
- 点击仪器库添加、单击器件选中、拖动沿 X/Z 移动；拖动空白环绕、滚轮缩放。
- 10 类器件：激光器、透镜、双缝、偏振片、观察屏、单缝、光栅、探测器、发生器、示波器。
- 最左侧激光器为活动光源，沿 +X 传播；横向偏差小于 1.5 cm 的下游器件参与，首个屏/探测器终止光路。
- 1 个场景长度单位 = 10 cm。薄透镜是近轴模型、光斑为定性示意；单缝/双缝/光栅为标量远场模型；光栅占空比 25%。偏振逐片应用马吕斯定律。
- 相对光源功率 1.0 对应 1 mW。探测器为线性响应与一阶 RC 负载。发生器和示波器自动连接，线缆为示意，暂不支持真实硬件和手动电路接线。
- 不包含非近轴反射光路、碰撞、噪声、暗电流、饱和、损伤和多衍射元件级联波场。混合光路按主模型呈现。

## 保存和备份

- 每份实验独立保存预习、对话、清单、笔记、数据、分析、草稿与三维场景。在实验记录间切换会恢复各自场景。
- 学习记录使用 `optilab-notebooks-v2` 浏览器存储，最多 30 份；无账户、无云同步。不同浏览器、端口和域名的存储独立。
- 关闭/重启浏览器后记录仍在；清除站点数据会丢失，请定期「导出实验备份」。JSON 导入以新记录合并，不覆盖现有记录，且重新校验计算结果。
- 三维场景的「保存实验 / 恢复实验」仍独立保留。三维场景不会在首次启动自动载入旧台面。
- 修改数据或模型会使旧分析解读及报告检查失效。报告提纲不会随数据自动重写，应在最终核对时重新检查。

## 工程结构

- `server.js`：本机 HTTP、开发与生产静态服务。
- `server/assistant.js`：AI 请求、上下文、限长、同源校验及错误处理。
- `src/learning.js` / `src/learning.css`：学习工作台与实验记录交互。
- `src/curriculum.js`：内置实验指导和仪器手册。
- `src/analysis.js`：解析、拟合、统计与报告规则检查。
- `src/notebooks.js`：实验备份与场景快照校验。
- `src/main.js` / `src/simulation.js` / `src/physics.js`：三维场景与物理仿真。
- `*.test.js`：公式、分析、场景、备份与 AI 接口测试。

本版本是**可本地使用的单用户完整流程应用**。若用于公网/班级教学，仍需另外增加账户、权限、课程管理、服务端数据存储、配额和部署配置。

## Git

`main` 分支的首个提交保留三维实验室基线；后续提交保存完整学习应用。未配置远程仓库，不会自动推送。`node_modules`、`dist`、`.env` 与日志不入库。
